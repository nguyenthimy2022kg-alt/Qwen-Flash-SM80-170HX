# 性能记录

记录日期：2026-09-08。本文件记录发布打包前的运行版本；后续发布打包的验证范围见使用说明。

## 最新一次长输出

硬件：双 CMP 170HX，SM80，每卡约 63.39 GiB 显存。双卡链路受 PCIe 2.0 ×4 限制，既有 P2P 大块带宽约 1.66 GB/s。

环境：vLLM `0.1.dev20073+g8e685d198`，PyTorch 2.13 + CUDA 13.0，Triton 3.7.1，Python 3.12；TEP2、MTP6、GDS、HC、TileLang、七行行号规划，以及完整词表 INT8＋原权重复核。

提示词为 **“写个网站网页”**；temperature=0、seed=0，先做 128 token 预热；正式输出上限 32768，允许自然结束。

两次测试的吞吐量差异约为 8.1%。由于输出内容、思考长度和上下文分布不同，该差异不代表固定增益。每轮推进与时间由总量折算，存在首尾误差。这里的 prefill 是短提示词成绩，不代表 8K～64K 输入。

最终服务健康检查通过，HTML 有关闭标签；只检查输出头尾，未进行网页浏览器功能验收。双卡各 580 个历史输入的草稿选词与原路径一致，非单行回退通过对应检查；该检查不覆盖任意输入的严格等价性或完整质量评估。

INT8 只用于单行草稿打分；主模型原 BF16 输出权重和接受规则保持不变。原词表权重仍在，每卡额外压缩权重和缩放约 323 MB。最新运行的 KV 缓存约 9.96/8.56 GiB，计算图约 0.69 GiB/卡。
