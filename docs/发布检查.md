# v0.2.0 发布检查

**简体中文** | [English](RELEASE_VALIDATION.en.md) · [返回首页](../README.md)

2026-10-02 在参考双 CMP 170HX 主机验收：固定 NVIDIA 检查点、TEP2、单个活动请求、同步调度。测试镜像由公开固定基础镜像和仓库源码重新构建，没有挂载研发运行目录或实验控制目录。

| 检查 | 结果 |
|---|---|
| CPU 检查 | 33 项通过，包含模型文件头、数据身份、复制失败清理、启动保护及内核哈希 |
| NVIDIA 加载视图 | 使用真实检查点生成；3,073 个保留张量的内容哈希与已使用版本一致；公开脚本生成的 PLE 映射一致 |
| 双卡通信 | 两个 rank 均通过 7 组形状／类型、非连续输入回退、输出独立性及 21 次交替图重放 |
| 功能和长上下文 | 28 个请求通过，包含一次主动取消及后续恢复 |
| 连续对话 | 同一个逐轮增长历史的会话，额外 20 轮通过 |
| 长输入与追问 | 初始输入 8,188／32,764／131,068／259,996 token，每档再追问两轮 |
| 图片、思考、工具 | 双图片识别、开关思考、工具调用与结果回传、JSON 输出、随机采样通过 |
| 结束与退出 | 46 次 `stop`、1 次 `tool_calls`、1 次客户端主动取消；返回用量合计 9,883 输出 token；服务退出码 0，无 OOM、无新增 Xid |
| 重复启动 | 成功拦截，未干扰正在运行的模型 |

保留当前已采用的计算代码。打包改动包括替换实验控制／内核路径、内置正在使用的草稿覆盖文件，以及在关闭追踪时不再写逐请求追踪记录。最终清理仅去除来源元数据中的私有目录和行尾空格；596 个安装后的运行文件哈希已核对；Python 语法树及全部内核／原生库哈希与 GPU 验收镜像一致。清单记录在 `patches/runtime-sha256.json`。

容器主机内存峰值约 20.09 GiB，结束前约 16.66 GiB，另有约 2.70 GiB swap。此处是包含文件缓存的 cgroup 数值，不是模型单独的 PSS，也不是显存；未触发主机内存保护停止。

这是单机有限范围回归，不能保证无限期运行稳定，也不是完整的原版 vLLM 质量对照或 128 张图片容量验收。接近上下文上限的测试使用短答案，不是生成 26 万输出 token。历史复制请求通过，不将其吞吐作为从零生成的测速。旧 RadixArk 性能记录单独保留。

## 在已启动服务上复现

```bash
python3 -m unittest discover -s tests -v
python3 tests/live_release.py --output runs/live-check --long-context
python3 tests/live_release.py --output runs/multiturn-check --soak-rounds 20
```

输出目录需尚不存在。可用 `--base-url`、`--model` 指定本地接口和模型名。测试串行执行，主体关闭思考、温度 0，另有开启思考和随机采样检查。双卡通信检查位于 `tests/gpu_communication.py`，需双进程、`Q38_PCIE_IPC=1` 和可写 `/evidence` 目录。
