# 来源与许可

## 固定基础

- [vLLM](https://github.com/vllm-project/vllm)：模型执行、Marlin、Triton 算子、推测生成及分布式运行基础。使用固定镜像 `vllm/vllm-openai:qwen38-flash-next@sha256:fc120ece0a388cc0aa1caad4a9f1cd92113484ab7ec2fd0efadd62585be05bf8`，镜像内版本 `0.1.dev20073+g8e685d198`。
- [Qwen3.8-Flash-DGX](https://github.com/blazux/qwen3.8-Flash-DGX)：本项目早期 PLE 接入与双卡适配工作所在仓库。保留其 Apache-2.0 许可和 Copyright 2026 blazux 声明，副本见 `licenses/qwen3.8-Flash-DGX-LICENSE`。
- [TileLang](https://github.com/tile-ai/tilelang)：单行输入投影编译工具，固定 0.1.14；配套 `apache-tvm-ffi==0.1.12`，下载文件按 PyPI 官方发布的 SHA256 锁定。依赖通过包管理器安装，仓库仅包含版本与校验信息。
- [NVIDIA GDS](https://docs.nvidia.com/gpudirect-storage/)：SSD 到 GPU 的 cuFile 通路；CUDA 与 cuFile 的许可独立于本仓库。

当前包的已采用源码来源为固定上游、保留的 GDS 运行镜像，以及本项目选定的 TEP2＋MTP6 运行源码。`patches/source-origins.json` 记录分类；`patches/upstream-sha256.json` 校验被覆盖的上游文件。构建时若上游源码不同，会先停止而非强行替换。

## 主机部署参考

- [qg19932GH/cmpunlocker](https://github.com/qg19932GH/cmpunlocker)：CMP 170HX 驱动层 P2P 部署参考，本仓库仅提供链接与集成说明，不复制其驱动源码。其许可独立适用。
- `docs/GDS_NVME_P2PDMA_REPRODUCTION.md`：根据原 Qwen3.8-Flash-DGX 项目的 GDS 实测文档整理，保留技术路径，替换设备标识并修订备份、恢复及平台适用范围说明。

## 自定义部分

包括 GDS 持久读取及生命周期交接、双卡 PLE 数据传递、HC 单行 GEMV、TileLang 单行输入投影、MTP 七行行号规划、全词表 INT8 打分与 BF16 候选复核，以及参数化启动和内存保护。保留来源文件原有版权声明；本仓库根目录 LICENSE 为 Apache-2.0。

`src/preload/` 为已选定环境中编译的 377 个 Triton CUDA 内核，包含文件名、加载名、共享内存要求和 SHA256。它们属于上述 vLLM/PyTorch/Triton 运行工作负载的编译产物，不包含模型权重。只适用于固定的软件栈和 SM80；源级计算实现在固定基础与本仓库源码中。它不是跨版本通用二进制库。

本仓库不包含模型权重、PLE 数据、真实隐藏状态采样文件或 CUDA/cuFile 安装包。模型和第三方软件保留各自的许可要求；本仓库许可证不改变它们的授权。
